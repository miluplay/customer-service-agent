# Soundcore 退换货政策

来源：https://www.soundcore.com/policies/refund-policy （官方公开政策，抓取于项目练习用途）

## 保修期限（按产品类别）

| 产品类别 | 保修期 |
|---|---|
| 音箱（Speaker）全系列 | 18个月 |
| 耳机/头戴式耳机（Headphones）全系列 | 18个月 |
| LED灯带 | 12个月 |
| Nebula X系列投影仪主机 | 2年 |
| Nebula X系列无线音箱/麦克风配件 | 1年 |
| 其他投影仪 | 12个月 |
| 翻新投影仪 | 3个月 |

## 30天无理由退货政策

- 未损坏的产品，购买后30天内可退货，**无论理由**，全额退款
- 例外：批量/企业订单（10件及以上）不适用此退货政策
- 退货件必须包含所有配件和原包装
- 非质量问题退货，运费由买家承担
- 商品寄回仓库检验后才会启动退款流程
- 众筹渠道（Kickstarter、Indiegogo等）购买的产品不适用此30天政策，需遵循对应众筹平台的退货规则

### 2025假日延长退货窗口期（特殊政策）
- 适用于2025年11月12日至12月31日期间下单的订单
- 可退货至2026年1月31日，或收货后30天内，以较晚者为准
- 仅适用于soundcore官网直接购买的订单

## 质量问题保修索赔（18个月内）

- 由soundcore或授权经销商销售的产品，质量类缺陷享受18个月保修
- 保修仅限购买所在国家/地区，跨境携带或转运至保修范围外地区将导致保修失效
- 处理方式：优先更换同等价值的官方翻新机；无翻新机时寄送全新品；如无法更换，按使用时长给予部分退款
- 换新后的保修期：以原保修期剩余时间或换新后3个月，以较长者为准
- 已获得全额退款的产品，保修自动失效

### 保修索赔所需材料
- 有效购买凭证（订单号、销售发票、或注明产品描述及价格的销售收据）
- 缺陷产品的序列号和/或缺陷照片证明
- 部分情况可能需要提供不止一种购买凭证

### 保修索赔时限
- 保修索赔申请提交后，**90天内必须完成处理**，超过90天或已超出原保修期，将无法继续处理

## 以下情况需买家自行承担运费

- 非质量问题的退货（任何非"确认缺陷"的理由）
- 保修产品被携带出原购买国后的索赔
- 买家操作失误导致的退货
- 退回个人物品
- 声称有缺陷但经soundcore质检确认为正常工作状态的退货
- 使用国际运输方式退回缺陷产品

## 不在保修范围内的情况

- 无法提供有效购买凭证
- 产品丢失或被盗
- 已超出保修期
- 非质量问题（购买30天后）
- 赠品/免费产品
- 经第三方维修过的产品
- 外部原因造成的损坏
- 误用造成的损坏（包括但不限于：跌落、极端温度、进水、操作不当）
- 从未授权渠道购买的产品

## 退货流程

1. 在soundcore官网提交退货申请（需提供订单号和购买时使用的邮箱）
2. 已有账号：可直接在订单历史里管理退货
3. 无订单号的访客：可用购买时的邮箱注册账号后查看订单历史
